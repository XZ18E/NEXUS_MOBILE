# NEXUS Calendar Mobile (Android)

Мобильная версия календаря на Kivy: календарь (месяц, свайп), события с повторами и напоминаниями,
задачи, статистика, тёмная и светлая темы. Данные хранятся в SQLite на телефоне. Интерфейс на русском.
Ядро (`models.py`, `database.py`) то же, что в десктопной версии.

> Готовый APK в архив **не** входит: для сборки нужен Android SDK/NDK, который скачивается при сборке.
> Ниже три способа получить APK. Сборка в этом проекте автором **не запускалась**, проверялся только код
> приложения на компьютере (виртуальный экран 400×800), поэтому при первой сборке возможны правки.

## Способ 1. Сборка в облаке GitHub (проще всего, ничего ставить не нужно)

1. Создайте аккаунт на https://github.com и новый репозиторий (можно приватный).
2. Загрузите в него **содержимое** этой папки (включая скрытую папку `.github`).
   Проще всего через «Add file → Upload files», перетащив все файлы и папки.
3. Откройте вкладку **Actions** → «Build APK» → **Run workflow**. Сборка идёт 15–40 минут.
4. По завершении откройте запуск и скачайте артефакт **NEXUS-Calendar-apk** (внутри `.apk`).

## Способ 2. Сборка на Windows через WSL или на Linux

```
sudo apt update
sudo apt install -y git zip unzip openjdk-17-jdk python3-pip autoconf libtool pkg-config \
    zlib1g-dev libncurses5-dev libncursesw5-dev libtinfo5 cmake libffi-dev libssl-dev
pip install --user buildozer cython
buildozer android debug
```
Готовый файл появится в папке `bin/`.

## Установка на телефон

1. Скопируйте `.apk` на телефон (кабель, мессенджер, облако).
2. Откройте файл. Android попросит разрешить установку из этого источника — разрешите.
3. Запустите «NEXUS Calendar». На Android 13+ разрешите уведомления.

APK подписывается отладочным ключом — этого достаточно для личного использования.
Для публикации в Google Play нужна `release`-сборка с вашим ключом (`buildozer android release`).

## Запуск на компьютере (для проверки)

```
pip install -r requirements.txt
python main.py
```
Данные в этом режиме лежат в папке данных Kivy вашей ОС.

## Новое в версии 1.1

- **Помощник** (вкладка с «искрой»): понимает русские фразы без интернета. Примеры: «Завтра в 15:00 встреча с Аней, напомни
  за час», «День рождения мамы 12 марта каждый год», «Каждый понедельник в 9 планёрка», «Добавь задачу купить билеты до
  пятницы», «Что у меня завтра?», «Найди врача», «Открой 5 ноября». Это разбор по правилам, а не нейросеть.
- **Повторение раз в год** (дни рождения, годовщины). 29 февраля в невисокосные годы переносится на 28 февраля.
- **Виджет «Сегодня»** на рабочий стол Android: события дня, число задач, ближайшее событие. Добавляется долгим нажатием на
  рабочем столе → «Виджеты» → NEXUS. Обновляется при каждом изменении и при открытии приложения.
- **Анимации**: плавный выезд сетки месяца при листании, поочерёдное появление карточек, пульсация кнопки «+»,
  появление окон и сообщений помощника.

## Что умеет

- Календарь: сетка месяца со свайпом влево/вправо, точки событий, значок задач, «Сегодня», панель выбранного дня.
- События: создание, правка, удаление с подтверждением, весь день, место, цвет, категории, напоминание,
  повторение (ежедневно/еженедельно/ежемесячно, «до даты»), проверка дат. Выбор даты и времени — встроенные окна.
- Задачи: приоритеты, срок, фильтры по статусу и приоритету, просроченные, счётчики, быстрый ввод, кнопка «+».
- Статистика: события по месяцам, распределение по категориям, показатели задач.
- Настройки: тема, первый день недели, напоминание по умолчанию, уведомления, экспорт CSV, резервная копия.
- Кнопка «Назад» закрывает окна и возвращает на календарь.

## Ограничения (важно)

- **Напоминания работают, пока приложение запущено**, в том числе свёрнуто (приложение не выгружается при сворачивании).
  Если систему выгрузила его из памяти или вы закрыли его смахиванием, уведомления не придут:
  для этого нужна фоновая служба или системный будильник, они не реализованы.
- Экспорт CSV/копии использует системное окно «Сохранить как…» — этот участок на реальном телефоне **не проверялся**.
  Если окно не откроется, файл остаётся в папке данных приложения, а путь показывается в сообщении.
- Нет восстановления из резервной копии внутри приложения.
- Виджет читает данные, которые приложение записывает при каждом изменении (на 30 дней вперёд). Если вы не открывали
  приложение дольше, список в виджете может устареть. Виджет не реагирует на нажатия по отдельным событиям: нажатие открывает приложение.
- Помощник не нейросеть: понимает типовые фразы, сложные и нестандартные формулировки может не разобрать.
- Нет синхронизации между устройствами.

```

editors.py    окна события и задачи
pickers.py    сетка месяца, выбор даты и времени
ui_kit.py     тема и виджеты
models.py, database.py   ядро (без графики)
buildozer.spec, .github/workflows/build-apk.yml   сборка APK
```
